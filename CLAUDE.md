# Development & Interaction Rule
- **Mandatory Git Commit & Push**: Setiap selesai mengerjakan perubahan kode atau tugas apapun, agen/developer wajib melakukan verifikasi build (`npm run build`), lalu langsung melakukan `git add`, `git commit -m "..."`, dan `git push origin main`.
